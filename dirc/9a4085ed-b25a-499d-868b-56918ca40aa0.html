🧪 テスト用Markdownファイル

これはGitのプッシュテストや、Markdownの表示確認を行うためのサンプルファイルです。

📝 1. テキスト装飾のテスト

  • 太字（Bold）のテキスト
  • 斜体（Italic）のテキスト
  • ~~打ち消し線（Strikethrough）のテキスト~~
  • インラインコード（Inline Code）

📋 2. リストのテスト

箇条書き（順不同）

  • アイテム A
  • アイテム B
    • 子アイテム B-1
    • 子アイテム B-2

番号付きリスト

  1. 最初のステップ
  2. 次のステップ
  3. 最後のステップ

タスクリスト

  • [x] 完了済みのタスク
  • [ ] 未完了のタスク

💻 3. コードブロックのテスト

def hello_world():
    # テスト用の関数です
    print("Hello, Git and Markdown!")

hello_world()

📊 4. テーブル（表）のテスト

| ステータス | コマンド | 説明 | | :--- | :--- | :--- | | 完了 | git init | リポジトリの初期化 | | 完了 | git push | リモートへの反映 | | 進行中 | test.md | テストファイルの追加 |

💡 5. 引用と補足

[!NOTE] これはGitHubなどで綺麗に装飾されるノート（補足説明）の記述テストです。

Markdownはシンプルで読みやすいドキュメントを簡単に作成できる軽量マークアップ言語です。
